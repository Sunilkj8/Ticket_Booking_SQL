🎟️ A MySQL-based Ticket Booking System that demonstrates advanced database concepts like 🔒 transactions, ⚡ pessimistic & optimistic locking, ⚠️ deadlock handling, 🗂️ isolation levels, 🔄 rollback management, and 👥 concurrent seat booking. The project simulates a real-world movie ticket booking system with ✅ secure seat allocation, ⏳ waiting queues, and 🛡️ automatic lock management.
